# Azhar Rudin — Portfolio

Responsive static portfolio prepared for GitHub Pages.

## Files

- `index.html` — main page
- `styles.css` — responsive styling
- `script.js` — mobile navigation and scroll reveal
- `assets/profile.png` — profile image cropped from the supplied CV

## Publish on GitHub Pages

1. Create a repository named `YOUR_USERNAME.github.io`.
2. Upload all files and folders in this project to the repository root.
3. Commit and push to the `main` branch.
4. Open `https://YOUR_USERNAME.github.io`.

For a normal repository name (for example `portfolio`), enable Pages in:
`Settings → Pages → Deploy from a branch → main / root`.

## Personalization

Before publishing, consider adding:
- GitHub profile URL
- LinkedIn URL
- selected projects with screenshots and repository links
- downloadable CV only if you are comfortable making the personal data inside it public

The site intentionally does not publish the phone number or date of birth from the source CV.
